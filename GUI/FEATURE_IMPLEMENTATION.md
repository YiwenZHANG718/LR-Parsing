# 功能实现详细说明

## 1. 分析器算法实现

### LR(0)分析器
- **项目集构造**: 使用闭包和转移函数构造LR(0)项目集族
- **分析表生成**: 基于项目集生成ACTION和GOTO表
- **冲突检测**: 检测移进-归约冲突和归约-归约冲突
- **适用范围**: 适用于LR(0)文法

### SLR(1)分析器
- **FOLLOW集计算**: 计算所有非终结符的FOLLOW集
- **冲突解决**: 使用FOLLOW集解决LR(0)的部分冲突
- **兼容性**: 向后兼容LR(0)，扩展支持更多文法
- **性能**: 相比LR(1)具有更小的状态空间

### LR(1)分析器
- **向前看符号**: 每个项目携带向前看符号信息
- **精确性**: 最精确的LR分析算法
- **状态合并**: 优化状态数量，提高效率
- **广泛适用**: 支持最大范围的LR文法

## 2. 数据结构设计

### 文法表示
```cpp
class Grammar {
    vector<Production> productions;    // 产生式集合
    set<string> terminals;            // 终结符集合
    set<string> nonterminals;         // 非终结符集合
    string start_symbol;              // 开始符号
};
```

### LR项目
```cpp
class LRItem {
    int production_id;                // 产生式编号
    int dot_position;                 // 点的位置
    set<string> lookaheads;           // 向前看符号集合
};
```

### 分析表
```cpp
struct ParseTable {
    map<pair<int, string>, Action> action_table;  // ACTION表
    map<pair<int, string>, int> goto_table;       // GOTO表
};
```

## 3. GUI界面功能

### 3.1 文法输入模块
- **文本编辑器**: 支持语法高亮的文法输入
- **文件操作**: 加载和保存文法文件
- **示例文法**: 内置多个测试用例
- **格式验证**: 实时检查文法格式正确性

### 3.2 分析器选择
- **算法切换**: 支持LR(0)/SLR(1)/LR(1)三种算法
- **参数配置**: 自动适配算法参数
- **性能提示**: 显示各算法的特点和适用性

### 3.3 结果展示
- **多标签页设计**: 
  - 分析结果: 总体信息和统计
  - ACTION表: 格式化的ACTION表显示
  - GOTO表: 格式化的GOTO表显示
  - 项目集: 详细的项目集信息
  - 分析过程: 逐步的语法分析过程

### 3.4 交互功能
- **实时分析**: 后台线程执行分析，不阻塞界面
- **进度显示**: 分析过程中的进度条和状态提示
- **错误处理**: 详细的错误信息和修复建议
- **结果导出**: 支持文本和JSON格式导出

## 4. 错误处理机制

### 4.1 文法错误
- **格式错误**: 检测产生式格式问题
- **符号错误**: 检测未定义符号引用
- **结构错误**: 检测循环定义等问题

### 4.2 分析冲突
- **移进-归约冲突**: 
  ```
  错误: 分析表构造失败
  ✗ 检测到冲突：
    移进/归约冲突在状态 5 符号 *
    移进/归约冲突在状态 6 符号 +
  ```
- **归约-归约冲突**: 显示具体的冲突状态和符号
- **解决建议**: 提供文法修改建议

### 4.3 输入串错误
- **词法错误**: 检测不合法的输入符号
- **语法错误**: 显示语法分析失败位置
- **恢复策略**: 提供错误恢复机制

## 5. 性能优化

### 5.1 算法优化
- **状态最小化**: 合并等价状态减少内存使用
- **表压缩**: 使用稀疏表示减少存储空间
- **计算缓存**: 缓存中间计算结果

### 5.2 界面优化
- **异步处理**: 使用多线程避免界面卡顿
- **增量更新**: 只更新变化的界面部分
- **内存管理**: 及时清理不需要的数据
