# LR语法分析器项目概述

## 项目简介

这是一个完整的LR语法分析器实现，包含C++后端和Python GUI前端，支持LR(0)、SLR(1)和LR(1)三种分析算法。

## 项目结构

### 核心组件

#### C++后端
- **lr_analyzer.cpp/h** - 主要分析器实现
- **lr_item.cpp/h** - LR项目集管理
- **grammar.cpp/h** - 文法处理
- **lr_cli.cpp** - 命令行接口
- **main.cpp** - 交互式主程序

#### Python前端
- **GUI/GUI.py** - 完整的中文图形界面

#### 配置文件
- **Makefile** - 构建配置
- **示例文法文件** - 测试用例

### 功能特性

#### 支持的分析算法
1. **LR(0)** - 基础LR分析
2. **SLR(1)** - 简单LR分析
3. **LR(1)** - 规范LR分析

#### 核心功能
- 文法输入和验证
- 分析表构造
- 项目集生成
- 输入串语法分析
- 详细的分析过程展示
- 冲突检测和报告
- 完整报告导出

#### 界面特性
- 完全中文化界面
- 响应式布局设计
- 多标签页展示
- 实时状态更新
- 错误详情显示

## 技术架构

### 后端技术栈
- **语言**: C++17
- **构建工具**: GNU Make
- **数据格式**: JSON输出
- **编码**: UTF-8

### 前端技术栈
- **语言**: Python 3
- **GUI框架**: Tkinter
- **字体支持**: 中文字体自适应
- **进程通信**: subprocess

### 数据流
```
文法输入 → C++分析器 → JSON数据 → Python GUI → 用户展示
```
