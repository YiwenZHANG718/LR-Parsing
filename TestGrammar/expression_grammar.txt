# 扩展算术表达式文法
# 特点：支持四则运算（加减乘除）和括号的完整表达式文法
# 复杂度：中等，包含所有基本算术运算
# 分析器兼容性：LR(0)有冲突，SLR(1)和LR(1)成功
# 典型输入示例：
#   - 四则运算: id + id - id * id / id
#   - 括号优先级: ( id + id ) * ( id - id )
#   - 复杂表达式: ( id + id * id ) / ( id - id )

E -> E + T
E -> E - T
E -> T
T -> T * F
T -> T / F
T -> F
F -> ( E )
F -> id
F -> num
