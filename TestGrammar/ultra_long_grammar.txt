# 超长无冲突LR文法
# 特点：大规模编程语言文法，包含完整的模块系统、类型系统、函数、控制结构
# 复杂度：高，151个产生式，支持模块导入、多种数据类型、复合结构
# 分析器兼容性：SLR(1), LR(1) （专门设计为无冲突）
# 典型输入示例：
#   - 变量声明: var id : bool ;
#   - 常量定义: const id = decimal ;
#   - 模块导入: import id ; var id : int8 = true ;
#   - 函数定义: func id ( ) { return decimal ; }
#   - 数组操作: var id : array [ decimal ] of bool = [ true , false ] ;
#   - 复合结构: import id ; const id = true ; func id ( ) { return id ; }
#   - 映射类型: var id : map [ string ] int16 = nil ;
#   - 函数签名: func id ( id : string , id : int32 ) : bool { return false ; }
# 设计思路：使用严格的层次结构和右递归避免冲突
