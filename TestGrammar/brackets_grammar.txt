# 括号匹配文法
# 特点：支持多种括号类型的嵌套匹配（圆括号、方括号、花括号）
# 复杂度：简单到中等
# 分析器兼容性：LR(0), SLR(1), LR(1)
# 典型输入示例：
#   - 简单表达式: id + id
#   - 圆括号嵌套: ( id + id )
#   - 方括号嵌套: [ id * id ]
#   - 花括号嵌套: { id + id * id }
#   - 混合嵌套: ( id + [ id * { id } ] )
#   - 复杂表达式: ( id + id ) * [ id + { id * id } ]

E -> E + T
E -> T
T -> T * F
T -> F
F -> ( E )
F -> [ E ]
F -> { E }
F -> id
